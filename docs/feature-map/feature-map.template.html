Run and deploy

02 / TEMPLATE, NOT A PRODUCT

Local: cp .env.example .env, bun install, add the CopilotKit Intelligence key and OPENAI_API_KEY, then bash scripts/start.sh and open http://localhost:3010. Production: image ghcr.io/copilotkit/openbot or Helm chart charts/openbot. Releases publish only from a labelled release/publish/vX.Y.Z PR.
